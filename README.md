Interview
==================
We have a simple terraform configuration for provisioning a basic docker container. There are some mistakes in the existing configuration. Our goal is to fix them until we can run terraform apply without issues.

### Notes:
* To get started clone all files into a directory
* To prepare the environment execute setup.sh
* The interview folder contains the variable definitions for the container
* Once the container is up and running you should be able to curl the exposed application and get the standard nginx langing page.
* You have sudo permissions.
